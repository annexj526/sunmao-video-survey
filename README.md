# Sunmao Video Survey Site

## 部署到 Vercel

1. 把这个文件夹上传到 GitHub 一个新仓库。
2. 打开 Vercel，点击 Add New Project。
3. 选择这个 GitHub 仓库。
4. Framework Preset 选择 Vite。
5. 点击 Deploy。

## Supabase 数据表

请先在 Supabase SQL Editor 运行：

```sql
create table sunmao_responses (
  id bigint generated by default as identity primary key,
  participant_id text,
  video_url text,
  video_page_start_time timestamptz,
  actual_time_on_video_page_seconds int,
  required_watch_seconds int,
  questionnaire_start_time timestamptz,
  submission_time timestamptz,
  responses jsonb,
  created_at timestamptz default now()
);

alter table sunmao_responses enable row level security;

create policy "Allow anonymous inserts"
on sunmao_responses
for insert
to anon
with check (true);
```
